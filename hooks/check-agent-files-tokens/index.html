    check-agent-files-tokens¶

    Fails when an AI agent guideline file exceeds a token budget. These files are loaded into the agent's context on every session, so every token in them is paid for on every request. Keep them short and move details into files the agent reads on demand.

    Usage¶

    repos:
  - repo: https://github.com/DimkaGorhover/pre-commit-hooks
    rev: v0.1.0
    hooks:
      - id: check-agent-files-tokens
        # optional
        args:
          - --max-tokens=4000
          - --encoding=cl100k_base

    Runs on the pre-commit, pre-push and manual stages.

    Checked files¶

    Pattern Tool
    AGENTS.md, AGENTS.local.md Codex, generic
    CLAUDE.md, CLAUDE.local.md, .claude/rules/*.md Claude Code
    GEMINI.md, GEMINI.local.md Gemini CLI
    .github/copilot-instructions.md, .github/instructions/*.instructions.md GitHub Copilot
    .cursorrules, .cursor/rules/*.mdc Cursor
    .windsurfrules Windsurf
    .clinerules Cline
    .<tool>/skills/**/*.md (e.g. .claude/skills, .agents/skills) Agent skills

    Root-level and nested files (e.g. services/api/AGENTS.md) both match. To check other files, override files: in your config.

    Hook definition 
    - id: check-agent-files-tokens
  name: check AI agent guideline files token budget
  description: >-
    fails when AGENTS.md, CLAUDE.md and similar agent guideline files exceed
    a token budget (default 2500, o200k_base).
  entry: check-agent-files-tokens
  language: python
  files: (?x)(
      (^|/)(AGENTS|CLAUDE|GEMINI)(\.local)?\.md$
      | (^|/)\.github/copilot-instructions\.md$
      | (^|/)\.github/instructions/[^/]+\.instructions\.md$
      | (^|/)\.(cursor|windsurf|cline)rules$
      | (^|/)\.cursor/rules/[^/]+\.mdc$
      | (^|/)\.claude/rules/[^/]+\.md$
      | (^|/)\.[^/]+/skills/.+\.md$
    )
  types:
    - text
  stages:
    - pre-commit
    - pre-push
    - manual

    Options¶

    Option Default Description
    --max-tokens 2500 Maximum tokens per file (must be ≥ 1)
    --encoding o200k_base tiktoken encoding used to count

    The default of 2500 follows Anthropic's advice to keep CLAUDE.md under ~200 lines, at roughly 12 tokens per markdown line.

    Needs network on first use

    tiktoken downloads the encoding file on first use and caches it (TIKTOKEN_CACHE_DIR). Offline with an empty cache, the hook fails with cannot load tiktoken encoding ....

    The count is an approximation

    tiktoken encodings are OpenAI's, not every vendor's tokenizer, but they are close enough for a budget.

    Example¶

    $ prek run check-agent-files-tokens --all-files
check AI agent guideline files token budget..............................Failed
CLAUDE.md: 3120 tokens > 2500 (move details into on-demand files)

    Run manually¶

    prek run check-agent-files-tokens --all-files

    pre-commit run check-agent-files-tokens --all-files

    check-agent-files-tokens --max-tokens 2500 AGENTS.md CLAUDE.md
