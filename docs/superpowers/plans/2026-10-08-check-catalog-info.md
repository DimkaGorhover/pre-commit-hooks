# check-catalog-info Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A prek/pre-commit hook `check-catalog-info` that requires a root Backstage `catalog-info.yaml`, adds the schema header and `metadata.namespace: default` when missing, and keeps the `endoflife.date/products` annotation in sync with the languages and tools the repo uses.

**Architecture:** One module `pre_commit_hooks/check_catalog_info.py` with three sections: an endoflife.date API client with a file cache in `$TMPDIR`, product/pin detection over `git ls-files`, and catalog editing. The leading `#` comment block is handled as text (ruamel drops it); the YAML body is round-tripped with ruamel.yaml and re-dumped only when an entity changed. One click command `main` wires it together and exits 1 on any fix or error.

**Tech Stack:** Python ≥3.10, click, ruamel.yaml, tomllib/tomli, urllib, pytest + click's `CliRunner`, uv, prek, mkdocs-material.

**Spec:** `docs/superpowers/specs/2026-10-08-check-catalog-info-design.md`

## Global Constraints

- Work only inside the worktree `.worktrees/feat-check-catalog-info` (branch `feat/check-catalog-info`); never switch branches.
- `requires-python = ">=3.10"` stays; `tomllib` on 3.11+, `tomli` on 3.10.
- New runtime dependencies: `ruamel.yaml>=0.18` and `tomli>=2; python_version < '3.11'`. No others.
- Lint/format with the repo's `.ruff.toml` (line length 120); the commit hooks run ruff and fail on unformatted code.
- Commits use Conventional Commits (`feat:`, `test:`, `docs:` …).
- Header line, verbatim: `# yaml-language-server: $schema=https://json.schemastore.org/catalog-info.json`
- Default namespace value: `default`. Annotation key: `endoflife.date/products`. Value format: `product@cycle` joined with `,`, **sorted by product**.
- Only `kind: Component` and `kind: Resource` get the annotation; every document gets the name/namespace checks.
- API: `https://endoflife.date/api/v1/products/<product>/`, 30 s timeout. Cache: `$TMPDIR/pre-commit-hooks-endoflife/<product>.json` via `tempfile.gettempdir()`; `--cache-ttl` default `86400`.
- Tests never touch the network: the `repo` fixture replaces `urllib.request.urlopen` with a function that raises.

## Review Focus

1. Empty `catalog-info.yaml` (only comments) → must fail with `no entities`, not pass silently. Test: Task 1 `test_empty_file`.
1. Trailing `---` (empty last document) → must not be reported as "metadata.name is required"; dropped on rewrite. Test: Task 1 `test_trailing_document_separator`.
1. `annotations:` key present but empty (YAML null) → filled in place, no duplicate key. Test: Task 4 `test_empty_annotations_key`.
1. Several `Component`/`Resource` entities in one file → each gets the annotation. Test: Task 4 `test_annotates_every_component`.
1. Monorepo layout (`package.json` only in a subdirectory, pin in root `.nvmrc`) and gitignored files (`node_modules/**/*.py`) → nodejs detected with the root pin; ignored files never detected. Test: Task 3 `test_detect` cases.
1. Annotation the hook knows is invalid (`gitlab`, `gitlab@1.0`) → reported, never rewritten. Test: Task 4 `test_invalid_annotation`.
1. API down with a stale cache, or `--offline` with a cache → cached cycles are used, so online and offline agree. Tests: Task 2 `test_releases_falls_back_to_stale_cache`, `test_releases_offline`; Task 4 `test_offline_uses_cache`.
1. Non-dict API payload or cache file → error message, no traceback. Tests: Task 2 `test_broken_cache_file_is_refetched`; Task 4 `test_bad_payload`.
1. Comments after a blank line in the leading comment block → kept on rewrite. Test: Task 1 `test_prelude_keeps_comments_after_blank_line`.

```python
from __future__ import annotations

import io
import os
import sys
from itertools import takewhile

import click
from ruamel.yaml import YAML
from ruamel.yaml.error import YAMLError

from pre_commit_hooks.util import project_dir

CATALOG = "catalog-info.yaml"
HEADER = "# yaml-language-server: $schema=https://json.schemastore.org/catalog-info.json"


# --- catalog-info.yaml editing -----------------------------------------------


def split_prelude(text: str) -> tuple[str, str]:
    """Leading comment and blank lines (ruamel drops comments before `---`) and the rest."""
    lines = text.splitlines(keepends=True)
    i = 0
    while i < len(lines) and (lines[i].startswith("#") or not lines[i].strip()):
        i += 1
    return "".join(lines[:i]), "".join(lines[i:])


def yaml_rt() -> YAML:
    y = YAML()
    y.preserve_quotes = True
    y.indent(mapping=2, sequence=4, offset=2)
    y.width = 4096  # never re-wrap long or folded scalars
    return y


@click.command()
def main() -> int:
    """Checks and fixes the repo's Backstage catalog-info.yaml."""
    root = project_dir()
    path = os.path.join(root, CATALOG)
    try:
        with open(path, encoding="utf-8") as f:
            text = f.read()
    except FileNotFoundError:
        click.echo(f"{CATALOG}: not found in {root}")
        sys.exit(1)

    fixes: list[str] = []
    errors: list[str] = []
    prelude, body = split_prelude(text)
    if not any(
        "yaml-language-server:" in line for line in takewhile(lambda line: line.startswith("#"), prelude.splitlines())
    ):
        prelude = HEADER + "\n" + prelude
        fixes.append("added yaml-language-server header")

    y = yaml_rt()
    y.explicit_start = body.lstrip().startswith("---")
    try:
        docs = list(y.load_all(body))
    except YAMLError as e:
        click.echo(f"{CATALOG}: {e}")
        sys.exit(1)
    if all(doc is None for doc in docs):
        click.echo(f"{CATALOG}: no entities")
        sys.exit(1)

    dirty = False  # body re-dumped only when an entity changed, so valid files stay byte-identical
    for i, doc in enumerate(docs):
        if doc is None:  # empty document, e.g. a trailing `---`
            continue
        meta = doc.get("metadata") if isinstance(doc, dict) else None
        if not isinstance(meta, dict) or not meta.get("name"):
            errors.append(f"document {i}: metadata.name is required")
            continue
        if "namespace" not in meta:
            meta.insert(list(meta).index("name") + 1, "namespace", "default")
            fixes.append(f"{meta['name']}: added metadata.namespace: default")
            dirty = True

    if dirty:
        out = io.StringIO()
        y.dump_all([doc for doc in docs if doc is not None], out)  # ruamel writes empty docs as `...`
        body = out.getvalue()
    if fixes:
        with open(path, "w", encoding="utf-8") as f:
            f.write(prelude + body)
    for message in fixes + errors:
        click.echo(f"{CATALOG}: {message}")
    sys.exit(1 if fixes or errors else 0)


if __name__ == "__main__":
    main()
```

```python
def serve_body(monkeypatch, body: bytes) -> None:
    """Fake API answering every product with `body`."""

    class Response:
        def __enter__(self):
            return self

        def __exit__(self, *exc):
            return False

        def read(self):
            return body

    monkeypatch.setattr(urllib.request, "urlopen", lambda url, timeout: Response())
```

```python
API = "https://endoflife.date/api/v1/products/{}/"
PRODUCT = re.compile(r"^[a-z0-9][a-z0-9.+-]*$")
VERSION = re.compile(r"\d+(?:\.\d+)*")
BAD_PAYLOAD = (ValueError, KeyError, TypeError)  # malformed JSON or unexpected shape


class UnknownProduct(Exception):
    pass


# --- endoflife.date API ------------------------------------------------------


def cache_dir() -> str:
    return os.path.join(tempfile.gettempdir(), "pre-commit-hooks-endoflife")


def releases(product: str, ttl: int, offline: bool = False) -> list[dict] | None:
    """Releases of `product`, newest first.

    A cache file younger than `ttl` is used as is; an older one only when the fetch fails.
    Offline: any cache file, or None when there is none.
    """
    if not PRODUCT.match(product):  # the name ends up in a URL and a file path
        raise UnknownProduct(product)
    path = os.path.join(cache_dir(), f"{product}.json")
    cached = None
    try:
        with open(path, encoding="utf-8") as f:
            cached = json.load(f)["result"]["releases"]
        if offline or time.time() - os.path.getmtime(path) < ttl:
            return cached
    except (OSError, *BAD_PAYLOAD):
        pass  # missing or broken cache entry: refetch
    if offline:
        return cached
    try:
        with urllib.request.urlopen(API.format(product), timeout=30) as r:
            data = r.read()
    except OSError as e:  # HTTPError and URLError are OSErrors
        if getattr(e, "code", None) == 404:
            raise UnknownProduct(product) from None
        if cached is not None:
            return cached  # stale beats nothing
        raise
    result = json.loads(data)["result"]["releases"]
    os.makedirs(cache_dir(), exist_ok=True)
    with open(path, "wb") as f:
        f.write(data)
    return result


def api_error(product: str, e: Exception) -> str:
    if isinstance(e, UnknownProduct):
        return f"{product}: unknown endoflife.date product"
    if isinstance(e, OSError):
        return f"{product}: endoflife.date API unreachable ({e}), use --offline"
    return f"{product}: bad endoflife.date API response ({e!r})"


def lowest(pin: str) -> str | None:
    """Lowest version in a pin or constraint: `>=3.10,<4` -> `3.10`, `latest` -> None."""
    # ponytail: first number, not the true lower bound (`<4,>=3.10` -> `4`); parse specifiers if that bites
    m = VERSION.search(pin)
    return m.group() if m else None


def to_cycle(version: str, cycles: list[str] | None) -> str:
    """Longest known cycle that `version` belongs to; `major.minor` when offline or unknown."""
    for c in sorted(cycles or (), key=len, reverse=True):
        if version == c or version.startswith(c + "."):
            return c
    return ".".join(version.split(".")[:2])


def latest(rels: list[dict]) -> str:
    """Newest non-EOL cycle, or the newest one if all are EOL."""
    return next((r["name"] for r in rels if not r.get("isEol")), rels[0]["name"])
```

```python
def repo_files(root: str) -> list[str]:
    out = subprocess.run(
        ("git", "ls-files", "--cached", "--others", "--exclude-standard"),
        cwd=root,
        capture_output=True,

        check=True,

def read(root: str, name: str) -> str | None:
    try:
        with open(os.path.join(root, name), encoding="utf-8") as f:
            return f.read()
    except OSError:
        return None


def first_line(root: str, name: str) -> str | None:
    text = read(root, name)
    return text.strip().splitlines()[0] if text and text.strip() else None


def load_json(root: str, name: str) -> dict:
    try:
        data = json.loads(read(root, name) or "{}")
    except ValueError:
        return {}
    return data if isinstance(data, dict) else {}


def load_toml(root: str, name: str) -> dict:
    try:
        return tomllib.loads(read(root, name) or "")
    except tomllib.TOMLDecodeError:
        return {}


def search(pattern: str, text: str | None) -> str | None:
    m = re.search(pattern, text or "", re.MULTILINE)
    return m.group(1) if m else None


def tool_pins(root: str) -> dict[str, str]:
    """Versions pinned in mise.toml / .mise.toml / .tool-versions, keyed by product."""
    pins: dict[str, str] = {}
    for line in (read(root, ".tool-versions") or "").splitlines():
        parts = line.split("#")[0].split()
        if len(parts) >= 2:
            pins[parts[0]] = parts[1]
    for name in (".mise.toml", "mise.toml"):  # mise.toml wins
        for tool, value in load_toml(root, name).get("tools", {}).items():
            if isinstance(value, list):
                value = value[0] if value else ""
            if isinstance(value, dict):
                value = value.get("version", "")
            pins[tool] = str(value)
    return {TOOL_ALIASES.get(tool, tool): pin for tool, pin in pins.items()}


def detect(root: str, files: list[str]) -> dict[str, str | None]:
    """Products used in the repo -> their pinned version (None when unpinned)."""
    names = {os.path.basename(f) for f in files}

    def has(*patterns: str) -> bool:
        return any(fnmatch(n, p) for n in names for p in patterns)

    package = load_json(root, "package.json")
    manager = str(package.get("packageManager", ""))
    tf = "\n".join(read(root, f) or "" for f in files if f.endswith(".tf"))
    tools = tool_pins(root)
    found: dict[str, str | None] = {}

    if has("*.py", "pyproject.toml"):
        found["python"] = first_line(root, ".python-version") or load_toml(root, "pyproject.toml").get(
            "project", {}
        ).get("requires-python")
    if "package.json" in names:
        found["nodejs"] = (
            first_line(root, ".nvmrc") or first_line(root, ".node-version") or package.get("engines", {}).get("node")
        )
    for product, lockfiles in (
        ("pnpm", ("pnpm-lock.yaml",)),
        ("yarn", ("yarn.lock",)),
        ("bun", ("bun.lock", "bun.lockb")),
    ):
        if has(*lockfiles):
            found[product] = manager.partition("@")[2] if manager.startswith(product + "@") else None
    if has("deno.json", "deno.jsonc"):
        found["deno"] = None
    if "go.mod" in names:
        found["go"] = search(r"^go\s+(\S+)", read(root, "go.mod"))
    if has("composer.json", "*.php"):
        found["php"] = load_json(root, "composer.json").get("require", {}).get("php")
        found["composer"] = None
    if "pom.xml" in names:
        found["eclipse-temurin"] = search(r"<maven\.compiler\.release>\s*(\d+)", read(root, "pom.xml"))
        found["apache-maven"] = None
    if has("build.gradle", "build.gradle.kts"):
        gradle = (read(root, "build.gradle") or "") + (read(root, "build.gradle.kts") or "")
        found["eclipse-temurin"] = search(r"JavaLanguageVersion\.of\((\d+)\)", gradle)
        found["gradle"] = search(
            r"gradle-(\d+(?:\.\d+)*)-",
            read(root, os.path.join("gradle", "wrapper", "gradle-wrapper.properties")),
        )
    if has("*.tf"):
        tofu = ".opentofu-version" in names or "opentofu" in tools
        found["opentofu" if tofu else "terraform"] = (
            first_line(root, ".opentofu-version") if tofu else None
        ) or search(r'required_version\s*=\s*"([^"]+)"', tf)
    if "Gemfile" in names:
        found["ruby"] = first_line(root, ".ruby-version")
    if "Cargo.toml" in names:
        found["rust"] = load_toml(root, "rust-toolchain.toml").get("toolchain", {}).get("channel")

    for product in found:
        if lowest(tools.get(product, "")):  # exact mise/asdf pin beats a range like `>= 1.11`
            found[product] = tools[product]
    return found
```

```python
def parse_products(value: object) -> dict[str, str]:
    """`python@3.12, nodejs@20` -> {"python": "3.12", "nodejs": "20"}."""
    out: dict[str, str] = {}
    for item in str(value or "").split(","):
        product, _, cycle = item.strip().partition("@")
        if product:
            out[product.strip()] = cycle.strip()
    return out


def resolve(
    detected: dict[str, str | None], offline: bool, ttl: int, errors: list[str]
) -> tuple[dict[str, str], dict[str, str]]:
    """Detected products -> (cycles from repo pins, newest cycles for unpinned products)."""
    pinned: dict[str, str] = {}
    fallback: dict[str, str] = {}
    for product, pin in sorted(detected.items()):
        version = lowest(pin) if pin else None
        try:
            rels = releases(product, ttl, offline)
        except (UnknownProduct, OSError, *BAD_PAYLOAD) as e:
            errors.append(api_error(product, e))
            continue
        if version:
            pinned[product] = to_cycle(version, [r["name"] for r in rels] if rels else None)
        elif rels:
            fallback[product] = latest(rels)
        elif offline:
            click.echo(f"{CATALOG}: {product}: no version pinned and nothing cached, skipped (--offline)")
    return pinned, fallback


def merge(
    existing: dict[str, str], pinned: dict[str, str], fallback: dict[str, str], fixes: list[str]
) -> dict[str, str]:
    products = dict(existing)
    for product, cycle in fallback.items():
        if product not in products:
            products[product] = cycle
            fixes.append(f"added {product}@{cycle} to {ANNOTATION}")
    for product, cycle in pinned.items():
        if product not in products:
            fixes.append(f"added {product}@{cycle} to {ANNOTATION}")
        elif products[product] != cycle:
            fixes.append(f"updated {product}@{products[product]} to {product}@{cycle} (repo pin)")
        products[product] = cycle
    return dict(sorted(products.items()))


def check_cycles(products: dict[str, str], offline: bool, ttl: int, errors: list[str]) -> None:
    for product, cycle in products.items():
        if not cycle:
            errors.append(f"{product}: missing @cycle in {ANNOTATION}")
            continue
        try:
            rels = releases(product, ttl, offline)
        except (UnknownProduct, OSError, *BAD_PAYLOAD) as e:
            errors.append(api_error(product, e))
            continue
        if rels is not None and cycle not in [r["name"] for r in rels]:  # None: offline, nothing cached
            errors.append(f"{product}@{cycle}: unknown cycle, see {API.format(product)}")


def set_annotation(meta: dict, value: str) -> None:
    annotations = meta.get("annotations")
    if annotations is None:
        keys = list(meta)
        after = max(keys.index(k) for k in ("name", "namespace", "title", "description") if k in keys)
        meta.insert(after + 1, "annotations", {ANNOTATION: value})
    else:
        annotations[ANNOTATION] = value
```

```python
    path = os.path.join(root, CATALOG)
    try:
        with open(path, encoding="utf-8") as f:
            text = f.read()
    except FileNotFoundError:
        click.echo(f"{CATALOG}: not found in {root}")
        sys.exit(1)

    fixes: list[str] = []
    errors: list[str] = []
    prelude, body = split_prelude(text)
    if not any(
        "yaml-language-server:" in line for line in takewhile(lambda line: line.startswith("#"), prelude.splitlines())
    ):
        prelude = HEADER + "\n" + prelude
        fixes.append("added yaml-language-server header")

    y = yaml_rt()
    y.explicit_start = body.lstrip().startswith("---")
    try:
        docs = list(y.load_all(body))
    except YAMLError as e:
        click.echo(f"{CATALOG}: {e}")
        sys.exit(1)
    if all(doc is None for doc in docs):
        click.echo(f"{CATALOG}: no entities")
        sys.exit(1)

    resolved = None
    dirty = False  # body re-dumped only when an entity changed, so valid files stay byte-identical
    for i, doc in enumerate(docs):
        if doc is None:  # empty document, e.g. a trailing `---`
            continue
        meta = doc.get("metadata") if isinstance(doc, dict) else None
        if not isinstance(meta, dict) or not meta.get("name"):
            errors.append(f"document {i}: metadata.name is required")
            continue
        if "namespace" not in meta:
            meta.insert(list(meta).index("name") + 1, "namespace", "default")
            fixes.append(f"{meta['name']}: added metadata.namespace: default")
            dirty = True
        if doc.get("kind") not in EOL_KINDS:
            continue
        if resolved is None:  # detection and API lookups only when an entity needs them
            resolved = resolve(detect(root, repo_files(root)), offline, cache_ttl, errors)
        current = (meta.get("annotations") or {}).get(ANNOTATION)
        fixes_before, errors_before = len(fixes), len(errors)
        products = merge(parse_products(current), *resolved, fixes)
        check_cycles(products, offline, cache_ttl, errors)
        if len(errors) > errors_before:  # never write an annotation we know is invalid
            del fixes[fixes_before:]
            continue
        value = ",".join(f"{p}@{c}" for p, c in products.items())
        if value and value != current:
            if len(fixes) == fixes_before:
                fixes.append(f"normalized {ANNOTATION}")
            fixes[fixes_before:] = [f"{meta['name']}: {fix}" for fix in fixes[fixes_before:]]
            set_annotation(meta, value)
            dirty = True

    if dirty:
        out = io.StringIO()
        y.dump_all([doc for doc in docs if doc is not None], out)  # ruamel writes empty docs as `...`
        body = out.getvalue()
    if fixes:
        with open(path, "w", encoding="utf-8") as f:
            f.write(prelude + body)
    for message in fixes + errors:
        click.echo(f"{CATALOG}: {message}")
    sys.exit(1 if fixes or errors else 0)
```

````markdown
# check-catalog-info

Makes sure the repository has a valid Backstage `catalog-info.yaml` at its
root and fixes what it can: the schema header, `metadata.namespace` and the
[endoflife.date](https://endoflife.date) `endoflife.date/products` annotation.
Like `end-of-file-fixer`, it fails the commit when it changed the file, so you
review and stage the fix.

## Usage

```yaml
repos:
  - repo: https://github.com/DimkaGorhover/pre-commit-hooks
    rev: <commit-sha>
    hooks:
      - id: check-catalog-info
```

Runs on every commit (`always_run`, no filenames) on the `pre-commit`,
`pre-push` and `manual` stages.

??? info "Hook definition"

    ```yaml
    --8<-- ".pre-commit-hooks.yaml:check-catalog-info"
    ```

## How it works

- Fails when `catalog-info.yaml` is missing, does not parse, or has no
    entities.
- Adds
    `# yaml-language-server: $schema=https://json.schemastore.org/catalog-info.json`
    when the leading comment block has no `yaml-language-server` header. Pair
    it with [check-yaml-schema](check-yaml-schema.md) to validate against the
    schema.
- Every entity needs `metadata.name`; a missing `metadata.namespace` becomes
    `namespace: default`.
- For `Component` and `Resource` entities the `endoflife.date/products`
    annotation (`product@cycle,...`, sorted) is kept in sync with the repo:
    - products are detected from files tracked by git (`*.py` → `python`,
        `package.json` → `nodejs`, lockfiles → `pnpm`/`yarn`/`bun`, `go.mod` →
        `go`, `composer.json`/`*.php` → `php` + `composer`, `pom.xml` →
        `eclipse-temurin` + `apache-maven`, `build.gradle(.kts)` →
        `eclipse-temurin` + `gradle`, `*.tf` → `terraform` or `opentofu`,
        `Gemfile` → `ruby`, `Cargo.toml` → `rust`, `deno.json` → `deno`);
    - the cycle comes from a repo pin: `mise.toml` / `.tool-versions` first,
        then `.python-version`, `requires-python`, `.nvmrc`, `engines.node`,
        `packageManager`, `go.mod`, `require.php`, `required_version`, ...;
    - a pinned cycle that differs from the annotation is rewritten;
    - an unpinned product gets the newest non-EOL cycle, but only when it is
        missing from the annotation;
    - products the hook cannot detect (e.g. `gitlab@19.3`) are kept;
    - every `product@cycle` is checked against
        `https://endoflife.date/api/v1/products/<product>/`.
- API responses are cached in `$TMPDIR/pre-commit-hooks-endoflife/`. A stale
    entry is still used when the API is unreachable. On Linux `$TMPDIR` is
    often the shared `/tmp`, so other local users could pre-seed it; that only
    affects which cycles the hook accepts.
- A file that is already valid is never rewritten; when it is, comments,
    quoting and folded scalars are preserved.
````
